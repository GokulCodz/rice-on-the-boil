About this tool

Every figure is labelled CALCULATED (computed now by physics.js), ILLUSTRATIVE (drawing or animation that only conveys an idea) or OBSERVED (your own kitchen measurements).

The idea of a guided, stage-by-stage investigation follows the course's continuity-equation learning tool; the design, physics engine and code here are original work for this project.

AI assistance: the code and page layout were drafted with an AI coding assistant (Claude) from the group's science file; equations, parameters and sources come from that file, and every number shown is reproduced by the verification suite and an independent Python check. See README.txt.
